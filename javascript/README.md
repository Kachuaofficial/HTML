# JavaScript Practice

This folder contains JavaScript practice files for learning scripting and interactivity.

## Files

- `main.js` — starter JavaScript file for practice code.

## How to use

1. Create or edit JavaScript files in this folder.
2. Link them from your HTML files using a relative path, for example:
   ```html
   <script src="../javascript/main.js"></script>
   ```
3. Open the HTML page in a browser and refresh to run your JavaScript.

## Tips

- Practice DOM manipulation, events, functions, and arrays.
- Keep practice scripts simple and test them in the browser console.
