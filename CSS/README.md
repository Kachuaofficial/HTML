# CSS Practice

This folder contains CSS practice files for styling web pages.

## Files

- `styles.css` — starter stylesheet for CSS experiments.

## How to use

1. Create or edit CSS files in this folder.
2. Link them from your HTML files using a relative path, for example:
   ```html
   <link rel="stylesheet" href="../CSS/styles.css">
   ```
3. Open the HTML page in a browser and refresh to see styling changes.

## Tips

- Use this folder for learning selectors, layout, colors, typography, and responsive design.
- Keep CSS practice files separate from the existing HTML folder styles.
