# Basic Web Development

This repository contains practice exercises for web development, organized into separate folders for HTML, CSS, and JavaScript.

## Folder structure

- `HTML/` — HTML practice files and small example pages.
- `CSS/` — CSS practice files and stylesheet exercises.
- `javascript/` — JavaScript practice files.

## How to use

- Open `HTML/index.html` or any HTML page in a browser to view markup examples.
- Use `CSS/styles.css` to practice styling and create new stylesheet files.
- Use `javascript/main.js` for JavaScript practice scripts.

## Notes

- The `HTML/` folder already contains its own `README.md` with details about the HTML examples.
- Add your CSS practice files to the `CSS/` folder.
- Add your JavaScript practice files to the `javascript/` folder.
