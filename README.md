# HTML Practice Collection

A curated HTML project workspace for hands-on web development practice. This repository contains sample pages, styling, media embedding, and layout experiments organized by day.

---

## 🌟 Overview

This workspace showcases HTML learning exercises across two days:

- `Day_1/` — Basic HTML structure, multimedia embedding, tables, forms, and CSS styling.
- `Day_2/` — Personal profile demo page with text formatting and simple HTML content.

---

## 📁 Project Structure

### Day_1
- `index.html` — HTML demonstration file with audio, table markup, and commented examples.
- `contactme.html` — Contact page skeleton for form or link examples.
- `page.html` — Additional HTML layout practice.
- `Resume.html` — Resume-style page template.
- `style.css` — Shared stylesheet for page styling.
- `audio.mp3` — Sample audio file embedded in `index.html`.
- `video.mp4` — Sample video file for media playback experiments.
- `profiel.jpeg` — Profile image used in page designs.

### Day_2
- `index.html` — Introduction page highlighting personal details and basic HTML formatting.

---

## 🎨 What You'll Find

- Clean HTML document structure with `DOCTYPE`, `head`, and `body`
- Text formatting using headings, paragraphs, bold, italics, underline, and strikethrough
- Media embedding with audio and video elements
- Table construction with headers and body rows
- CSS styling via external stylesheet
- Simple page layout examples for resumes and profiles

---

## 🚀 How to Use

1. Open the `Day_1/index.html` or `Day_2/index.html` file in a browser.
2. Review the markup and explore the page structure.
3. Edit content or styling in `style.css` to customize the appearance.
4. Refresh the browser to see live updates.

---

## 💡 Tips for Improvement

- Add navigation links between pages to create a small multi-page site.
- Enhance `Resume.html` with modern layout and responsive styling.
- Replace placeholder content with real portfolio details.
- Add a contact form to `contactme.html`.
